Cloudflare Worker 代理代码

这个代理把 CloudConvert 和 MinerU 的密钥留在服务端，并帮浏览器绕过 OSS/CDN 的跨域限制。 MinerU 精准解析必须配好代理才能用（token 不能放进前端代码，且每 14 天过期一次）。
1. 打开 Cloudflare Dashboard → Workers & Pages → 创建 Worker；
2. 粘贴下面这份代码，在 Settings → Variables 里加两个 Secret：CLOUDCONVERT_API_KEY、MINERU_API_TOKEN，部署；
3. 把 Worker 地址填回上方"代理地址"输入框并保存。
MinerU token 到 这里领取，过期后只需更新 Secret，不用重新部署。

支持的格式

客户端转换 免费

  • XLSX / XLS / CSV / TSV → CSV, TSV, XLSX, JSON, HTML, PDF
  • JSON → XLSX, CSV, HTML
  • DOCX → HTML, TXT (提取文本)
  • Markdown → HTML, TXT
  • HTML → TXT
  • SVG → PNG, JPEG, WebP
  • PNG / JPEG / WebP / BMP / GIF → 互转, PDF（GIF 取首帧）
  • 导出 GIF 走 CloudConvert（浏览器 canvas 编不了 GIF）

API 转换 MinerU + CloudConvert

  • PDF → DOCX, MD, HTML, TXT（配好代理后走 MinerU，精度更高）
  • PDF → PNG, JPG, EPUB, PPTX（CloudConvert）
  • DOCX → PDF, HTML, TXT, PNG, JPG
  • XLSX → PDF, CSV, HTML, PNG
  • PPTX → PDF, PNG, JPG, HTML
  • EPUB → PDF, MOBI, HTML
  • 以及更多 200+ 格式...

限制说明

  • 客户端转换: 无限制，离线可用
  • MinerU 精准解析: 需在 Worker 上配 token，免费 1000 页/天，单文件 ≤200 页
  • MinerU token 每 14 天过期，过期后更新 Worker Secret 即可
  • CloudConvert 免费版: 25 次/天
  • 单文件最大: 客户端 50MB / API 100MB
  • API Key 仅存在浏览器本地；配了 Worker 则由 Worker 持有密钥
