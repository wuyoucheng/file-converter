Cloudflare Worker 代理代码

1. 登录 Cloudflare Dashboard → Workers & Pages → 创建 Worker
2. 粘贴以下代码，将 YOUR_API_KEY 替换为你的 CloudConvert API Key
3. 部署后把 Worker 地址填入上方"代理地址"输入框 

// cloudflare-worker.js
// Cloudflare Worker - CloudConvert API 代理
// 部署: wrangler deploy 或通过 Cloudflare Dashboard

export default {
  async fetch(request, env) {
    // CORS
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        headers: {
          'Access-Control-Allow-Origin': '*',
          'Access-Control-Allow-Methods': 'POST, GET, OPTIONS',
          'Access-Control-Allow-Headers': 'Content-Type',
        }
      });
    }

    const API_KEY = env.CLOUDCONVERT_API_KEY || 'YOUR_API_KEY';
    const corsHeaders = {
      'Access-Control-Allow-Origin': '*',
      'Content-Type': 'application/json',
    };

    try {
      const url = new URL(request.url);
      const path = url.pathname;

      // POST /jobs - 创建转换任务
      if (path === '/jobs' && request.method === 'POST') {
        const body = await request.text();
        
        const ccResponse = await fetch('https://api.cloudconvert.com/v2/jobs', {
          method: 'POST',
          headers: {
            'Authorization': `Bearer ${API_KEY}`,
            'Content-Type': 'application/json',
          },
          body: body,
        });

        const data = await ccResponse.json();
        return new Response(JSON.stringify(data), {
          status: ccResponse.status,
          headers: corsHeaders,
        });
      }

      // POST /jobs/:id/start - 启动任务
      if (path.match(/^\/jobs\/[^/]+\/start$/) && request.method === 'POST') {
        const jobId = path.split('/')[2];
        
        const ccResponse = await fetch(`https://api.cloudconvert.com/v2/jobs/${jobId}/start`, {
          method: 'POST',
          headers: { 'Authorization': `Bearer ${API_KEY}` },
        });

        const data = await ccResponse.json();
        return new Response(JSON.stringify(data), {
          status: ccResponse.status,
          headers: corsHeaders,
        });
      }

      // GET /jobs/:id - 查询任务状态
      if (path.match(/^\/jobs\/[^/]+$/) && request.method === 'GET') {
        const jobId = path.split('/')[2];
        
        const ccResponse = await fetch(`https://api.cloudconvert.com/v2/jobs/${jobId}`, {
          headers: { 'Authorization': `Bearer ${API_KEY}` },
        });

        const data = await ccResponse.json();
        return new Response(JSON.stringify(data), {
          status: ccResponse.status,
          headers: corsHeaders,
        });
      }

      return new Response(JSON.stringify({ error: 'Not found' }), {
        status: 404,
        headers: corsHeaders,
      });
    } catch (e) {
      return new Response(JSON.stringify({ error: e.message }), {
        status: 500,
        headers: corsHeaders,
      });
    }
  }
};

支持的格式

客户端转换 免费

  • XLSX / CSV / TSV → CSV, XLSX, JSON, HTML
  • JSON / CSV → XLSX, CSV, JSON
  • DOCX → HTML, TXT (提取文本)
  • Markdown → HTML, TXT
  • HTML → TXT, MHT
  • SVG → PNG, JPEG, WebP
  • PNG / JPEG / WebP / BMP / GIF → 互转, PDF

API 转换 CloudConvert

  • DOCX → PDF, HTML, TXT, PNG, JPG
  • XLSX → PDF, CSV, HTML, PNG
  • PPTX → PDF, PNG, JPG, HTML
  • PDF → DOCX, PNG, JPG, TXT, HTML
  • EPUB → PDF, MOBI, HTML
  • 以及更多 200+ 格式...

限制说明

  • 客户端转换: 无限制，离线可用
  • CloudConvert 免费版: 25 次/天
  • 单文件最大: 客户端 50MB / API 100MB
  • API Key 仅存在浏览器本地
